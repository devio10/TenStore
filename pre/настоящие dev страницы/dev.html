TenID API предоставляет доступ к системе аккаунтов для приложений и сайтов. С помощью TenID можно хранить данные пользователя, к примеру, его библиотеку музыки.
В этой документации описано, как обращаться к API.

Вход в аккаунт

Для входа в аккаунт нужно отправить POST запрос такого вида:

https://thetenstore.ru/api?action=login&appcode=$code&login=$login&password=$password

$code — уникальный код вашего приложения/сайта,
$login — логин пользователя (в зашифрованном виде),
$password — пароль пользователя (в зашифрованном виде).

Получение данных

Чтобы получить ранее записанные в профиль данные вашего приложения, отправьте POST запрос:

https://thetenstore.ru/api?action=getdata&appcode=$code

$code — уникальный код вашего приложения/сайта.
Сервер отправит json со всеми данными.

Изменение данных

Если необходимо изменить данные в профиле, POST запрос должен выглядеть так:

https://thetenstore.ru/api?action=modifydata&appcode=$code&par=$parameter&dataaction=$paraction&value=$value

$code — уникальный код вашего приложения/сайта,
$parameter — название параметра, который необходимо изменить,
$dataaction — действие, которое необходимо выполнить с параметром,
$value — новое значение параметра.
Можно выполнить два действия с параметром: удалить или изменить. Чтобы удалить параметр, переменная dataaction должна иметь значение remove, если значение параметра нужно изменить, отправьте dataaction со значением change. В первом случае, переменная value не отправляется.
